# Module 1 lab: the enterprise meaning problem

You need Python 3.13 and VS Code. Nothing else is installed: the lab uses only the Python
standard library, and the warehouse is a SQLite file that Python creates.

All data in this lab is fictional and is generated by `setup_warehouse.py`. No language model is called.

## Start

1. In VS Code choose File, Open Folder and open this folder.
2. Open a terminal with Terminal, New Terminal.
3. Check Python: `python --version` (on macOS or Linux use `python3` if `python` is not found; on Windows `py` also works).
4. Build the warehouse: `python setup_warehouse.py`

## Labs

| Lab | File | You produce |
|---|---|---|
| 1 | `lab1_three_definitions.py` | Two SQL queries and four counts of "active customers" |
| 2 | `lab2_baseline.py`, then `check_classification.py` | A kind of inconsistency for each failed question in `failures.csv` |
| 3 | `lab3_wilson.py` | A working `wilson()` function and a one-sentence conclusion |
| 4 | `adr/0001-semantic-ownership.md`, then `check_adr.py` | ADR 1 for the retailer in `case_brief.md` |

Each script prints what is still to do. Worked answers are in the `solutions` folder.
Run a worked answer from this folder, for example `python solutions/lab3_wilson.py`. It reads the same data files and overwrites the output files in this folder.
The VS Code Python extension is optional. Everything here runs from the terminal.
To look inside the database, run `python -m sqlite3 retail.db` and type SQL at the prompt (`.quit` to leave).

## Doing the lab again

Run `python reset.py`. It saves the files you changed to a new folder named `my_work_<date>_<time>`, deletes the files
the scripts generated, and puts every lab file back as it was when you received it. Then start again from the top of this page.
Add `--yes` to skip the question it asks. Do not edit the `reset_files` folder, which holds the original files.
